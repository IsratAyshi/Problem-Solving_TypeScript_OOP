# TypeScript & OOP Assignment

This repository contains my solutions for the **Problem Solving with
TypeScript & OOP** assignment. It includes eight TypeScript problems
covering functions, union types, readonly tuples, generics, interfaces,
and OOP.

## Files

-   [`solutions.ts`](./solutions.ts) --- Contains the solutions to all
    eight coding problems, including array operations, generic
    functions, classes, and async Promise handling.
-   [`type-vs-interface.md`](./type-vs-interface.md) --- Explains the
    differences between `type` aliases and `interface` in TypeScript,
    with examples.
-   [`access-modifiers.md`](./access-modifiers.md) --- Explains
    `public`, `private`, `protected`, and `readonly` access modifiers in
    TypeScript OOP, with examples.

## Topics Covered

-   Optional parameters and default values
-   Union types and type narrowing
-   Readonly tuples
-   Generics, rest parameters, and `keyof`
-   Interfaces and array filtering
-   Classes and inheritance
-   Asynchronous functions and `Promise<string>`
